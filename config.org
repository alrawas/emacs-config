* ALL THE ICONS
Two icon systems are in play, and they are not interchangeable.  =all-the-icons=
serves dired, ivy-rich and the doom-themes neotree config; its glyphs come from
six TTFs that =all-the-icons-install-fonts= downloads, or that can be copied
straight out of =elpaca/repos/all-the-icons/fonts/= when GitHub is unreachable.

=nerd-icons= is the newer one, and what doom-modeline 4.x and dashboard 1.9 both
reach for first.  It asks for the family =Symbols Nerd Font Mono=, which is not
installed here -- so point it at the Nerd Font that is, the same one the default
face uses.  A =setq= before the package loads survives, since =defcustom= leaves
an already-bound variable alone.

#+begin_src emacs-lisp
(setq nerd-icons-font-family "IosevkaTerm Nerd Font Mono")

(use-package all-the-icons
  :ensure t
  :if (display-graphic-p))

(use-package all-the-icons-dired
  :hook (dired-mode . (lambda () (all-the-icons-dired-mode t))))
#+end_src

* BACKUP 
By default, Emacs creates automatic backups of files in their original directories, such "file.el" and the backup "file.el~".  This leads to a lot of clutter, so let's tell Emacs to put all backups that it creates in the =TRASH= directory.

#+begin_src emacs-lisp
(setq backup-directory-alist '((".*" . "~/.Trash")))
#+end_src

* DIRED
=dired-open= hands a file to an external program based on its extension.  Naming
programs directly means the config breaks on any machine that lacks them, and it
breaks *silently*: with =dired-open-use-nohup= at its default =t= the handler
runs =sh -c "nohup <prog> ..."=, =sh= always exists, so =start-process= returns a
live process, =dired-open-by-extension= reports success, and =dired-open-file=
never reaches its =dired-find-file= fallback.  The key just does nothing.

=xdg-open= avoids all of that by following the desktop's own MIME handlers --
here Loupe for images and VLC for video -- and keeps following them if those
ever change.  =E= (=dired-do-open=) is the built-in equivalent in Emacs 30+.

#+begin_src emacs-lisp
(use-package dired-open
  :config
  (setq dired-open-extensions
        (mapcar (lambda (ext) (cons ext "xdg-open"))
                '("gif" "jpg" "jpeg" "png" "webp" "svg" "bmp"
                  "mkv" "mp4" "webm" "avi" "mov" "gifv"
                  "mp3" "flac" "ogg" "wav" "opus"
                  "pdf" "epub" "odt" "docx" "xlsx"))))

(use-package peep-dired
  :after dired
  :hook (evil-normalize-keymaps . peep-dired-hook)
  :config
  (evil-define-key 'normal dired-mode-map (kbd "h") 'dired-up-directory)
  (evil-define-key 'normal dired-mode-map (kbd "l") 'dired-open-file) ; use dired-find-file instead if not using dired-open package
  (evil-define-key 'normal peep-dired-mode-map (kbd "j") 'peep-dired-next-file)
  (evil-define-key 'normal peep-dired-mode-map (kbd "k") 'peep-dired-prev-file)
  )

* MAGIT
Git porcelain.  Held behind =:commands= so magit's load cost -- it pulls in
=transient=, =with-editor= and =compat= -- is paid the first time you press
=SPC g g=, not at every startup.

=magit-display-buffer-same-window-except-diff-v1= keeps the status buffer in the
window you were already in; diffs and logs still get their own.  Without it
magit splits the frame every time, which fights the single-window habit the rest
of this config has.

=magit= and =magit-section= are listed in =evil-collection-mode-list= up in
*Load Evil Mode*, and they have to be: in evil's normal state =s= is
=evil-substitute=, =u= is =evil-undo=, =x= is =evil-delete-char= and =c= is the
=evil-change= operator -- which are magit's stage, unstage, discard and commit
keys.  Without that entry the status buffer is unusable.

The =compat= and =transient= lines are not optional here.  Emacs 30.2 bundles
both -- =compat= 30.2.9999 and =transient= 0.7.2.2 -- and elpaca builds
=elpaca-ignored-dependencies= from =package--builtin-versions=, so it will never
install over a built-in unless the package is asked for *by name*.  Magit 4.7
wants =compat= 31.1 and =transient= 0.13, so without these two declarations the
install fails with "compat installed version 30.2.9999 lower than min required
31.1", which then fails =llama=, then =with-editor=, then =magit=.

No =elpaca-wait= is needed, and adding one here breaks the rest of this file:
it splits elpaca's queue mid-config and aborts the load, so every section below
MAGIT silently never runs.  It is also pointless, because =elpaca--check-version=
prefers a *queued* order over a built-in no matter where in the queue it sits --
=(unless dep (elpaca-alist-get id package--builtin-versions))=.  Declaring the
two packages at all is the whole fix.

#+begin_src emacs-lisp
;; Install over the too-old built-ins.
(use-package compat :demand t)
(use-package transient :demand t)

(use-package magit
  :commands (magit-status magit-status-here magit-dispatch magit-file-dispatch
             magit-blame-addition magit-log-current magit-log-buffer-file
             magit-diff-buffer-file magit-clone magit-init)
  :config
  ;; Status in the window you came from; diffs and logs get their own.
  (setq magit-display-buffer-function
        #'magit-display-buffer-same-window-except-diff-v1)
  ;; Highlight the changed words inside a changed line, not just the line.
  (setq magit-diff-refine-hunk 'all))

  (make-directory (expand-file-name "writing" org-directory) t)
  (expand-file-name (format-time-string "writing/%Y.org") org-directory))

(defun my/org-write-today ()
  "Open this year's writing file at today's entry, creating it at the top.
Point lands after whatever is already written there, so a second sitting on the
same day continues the same entry instead of starting a new one."
  (interactive)
  (find-file (my/org-writing-file))
  (let ((today (format-time-string "* [%Y-%m-%d %a]")))
    (goto-char (point-min))
    (unless (search-forward today nil t)
      ;; newest first, but below any #+keyword lines at the top
      (goto-char (point-min))
      (while (looking-at "^[#\n]") (forward-line 1))
      (insert today "\n\n"))
    (org-back-to-heading t)
    (org-end-of-subtree t t)
    (skip-chars-backward " \t\n")
    (insert "\n"))
  (recenter))
#+end_src

** Auto Frontmatter for New Org Files
Automatically insert org frontmatter (title, date, author, description, filetags) when creating a new =.org= file.  The title is derived from the filename, and the date is set to the current date.

#+begin_src emacs-lisp
(defun my/org-auto-frontmatter ()
  "Insert org frontmatter when a new org file is created."
  (when (and (eq major-mode 'org-mode)
             (= (buffer-size) 0))
    (let* ((filename (file-name-sans-extension
                      (file-name-nondirectory (buffer-file-name))))
           (title (replace-regexp-in-string "[_-]" " " filename))
           (title (capitalize title))
           (date (format-time-string "[%Y-%m-%d %a]")))
      (insert (format "#+title: %s\n#+date: %s\n#+author: %s\n#+description: \n#+filetags: \n\n"
                      title date user-login-name))
      (search-backward "#+description: ")
      (end-of-line))))

(add-hook 'find-file-hook #'my/org-auto-frontmatter)

* TODO.TXT
Open tasks live in =~/org/todo.txt= in todo.txt format: one self-contained line
each, carrying its own =+project=, =@context= and =due:= date, so nothing
depends on a parent heading. =todotxt.el= edits it here, =tuxedo= edits the same
file in the terminal, and neither owns it. =A= archives completed lines to the
sibling =~/org/done.txt=, which is the same file tuxedo archives to.

=SPC a= opens it. Inside: =a= add, =e= edit, =c= toggle complete, =r= priority,
=d= due date, =t= tag, =/= filter for, =\\= filter out, =l= clear filters,
=i= hide done, =A= archive, =R= reload, =u= undo, =q= bury, =?= the full list.
=SPC= stays the leader, so every other binding still works from in there.

Filters are invisible by default -- hidden lines just aren't there, with nothing
saying why. The header line names what is being filtered out and how many lines
that costs you, so =l= never has to be a guess.

#+begin_src emacs-lisp
(defun my/todotxt-filter-label (f)
  "Readable name for one predicate in `todotxt-active-filters'.
The keyword filters are lambdas built at runtime, so the word has to be read
back out of the lambda's own source."
  (if (eq f 'todotxt-complete-p)
      "done hidden"
    (let* ((flat (format "%S" f))
           (word (and (string-match "line-match \"\\([^\"]+\\)\"" flat)
                      (match-string 1 flat))))
      (cond ((null word) "a filter")
            ((string-match-p "(not " flat) (concat "only " word))
            (t (concat "without " word))))))

(defun my/todotxt-header ()
  "Header line for todo.txt: what is filtered, and what it is hiding."
  (let* ((hidden (length (seq-filter
                          (lambda (o) (eq (overlay-get o 'invisible) t))
                          (overlays-in (point-min) (point-max)))))
         (total (save-excursion
                  (save-match-data
                    (how-many "^[^[:space:]]" (point-min) (point-max)))))
         (labels (delete-dups (mapcar #'my/todotxt-filter-label
                                      todotxt-active-filters))))
    (if (null labels)
        (propertize (format " %d task%s" total (if (= total 1) "" "s"))
                    'face 'shadow)
      (concat

=todotxt.el='s own =todotxt-archive= is broken: it appends each line to
=done.txt= without a trailing newline, so the next one lands on the same line,
and its loop body returns =t= unconditionally, so if a delete ever fails to
advance point it appends the same line forever. That hangs Emacs and corrupts
=done.txt=. This replaces it.

#+begin_src emacs-lisp
(defun my/todotxt-archive ()
  "Move every completed line out of todo.txt and onto the end of done.txt.
Collects the lines first and writes them in one go, each newline-terminated, so
a missing final newline cannot concatenate records. The loop always advances."
  (interactive)
  (todotxt-remove-overlays)
  (let ((done '())
        (target (expand-file-name "done.txt" (file-name-directory todotxt-file))))
    (save-excursion
      (goto-char (point-min))
      (let ((inhibit-read-only t))
        (while (not (eobp))
          (if (and (not (todotxt-line-empty-p)) (todotxt-complete-p))
              (progn
                (push (buffer-substring-no-properties
                       (line-beginning-position) (line-end-position))
                      done)
                ;; deleting leaves point at the start of the next line already
                (delete-region (line-beginning-position)
                               (min (point-max) (1+ (line-end-position)))))
            (forward-line 1)))))
    (if (null done)
        (message "Nothing completed to archive")
      (setq done (nreverse done))
      (with-temp-buffer
        (insert (mapconcat #'identity done "\n") "\n")
        (write-region (point-min) (point-max) target t 'silent))
      (when todotxt-save-after-change (save-buffer))
      (todotxt-apply-active-filters)
      (message "Archived %d line%s to done.txt"
               (length done) (if (= (length done) 1) "" "s")))))
#+end_src

* TRANSPARENCY
With Emacs version 29, true transparency has been added.  

A standalone Emacs builds its *first* frame before init.el runs, so
=default-frame-alist= alone never reaches it. Set all three: the default for
later frames, the initial frame, and any frame that already exists by the time
init finishes. The last hook covers daemon clients.

#+begin_src emacs-lisp
(defvar my/frame-alpha 90
  "Background transparency for every frame, 0 (clear) to 100 (opaque).")

(defun my/apply-alpha (&optional frame)
  "Give FRAME the configured background alpha, or every frame if none is given."
  (dolist (f (if (framep frame) (list frame) (frame-list)))
    (set-frame-parameter f 'alpha-background my/frame-alpha)))

(add-to-list 'default-frame-alist (cons 'alpha-background my/frame-alpha))
(add-to-list 'initial-frame-alist (cons 'alpha-background my/frame-alpha))
(add-hook 'after-init-hook #'my/apply-alpha)
(add-hook 'server-after-make-frame-hook #'my/apply-alpha)
#+end_src
